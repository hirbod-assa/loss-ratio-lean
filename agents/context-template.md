# Problem context (shared by all agents)

Fill in this file before running any agent. Every agent reads it first, so keep it precise and self-contained.

## 1. Setting
Spaces, objects and conventions, with notation. State conventions for degenerate values (for example 0/0, infinite
values, labels) explicitly.

## 2. Target
The type of result sought, for example "necessary and sufficient conditions on F for F = A/B with A, B in class C".
Write the intended theorem with all quantifiers if it is known; otherwise describe the class of acceptable answers.

## 3. Established facts (do not rediscover)
Numbered facts already proved or checked, with references or script names.

## 4. Traps and degenerate cases (test every claim against these)
Numbered list: degenerate sets, boundary cases, relabelling or reparametrization traps, cancellations.

## 5. Constraints set by the author
What a proposal may and may not use (for example "axioms may refer only to values of F"; "no derived functional,
even as an abbreviation").

## 6. Notation file
One table of symbols and sign conventions. Agents must not change it.

## 7. Files and permissions
Where the draft is, which files are read-only, where scratch scripts go (for example `ai_process/panels/<run>/`).
Agents never commit, push or send anything.

## 8. Deliverable
The structured output expected from each role (see the agent files).
